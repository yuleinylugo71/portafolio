Sobre mí

Soy estudiante de Análisis y Desarrollo de Software, enfocada en crear soluciones digitales útiles, claras y bien estructuradas.

Me interesa construir aplicaciones que conecten diseño, lógica y datos para resolver necesidades reales. En mis proyectos he trabajado interfaces web, aplicaciones progresivas, sistemas backend, bases de datos e integraciones, cuidando tanto la experiencia del usuario como el orden técnico del código.

Proyectos Seleccionados

AgroTrace

PWA / Trazabilidad Agrícola / Experiencia de Campo

React Node.js PostgreSQL

AgroTrace digitaliza el seguimiento de cultivos desde la finca hasta la entrega final. La plataforma permite registrar lotes, consultar estados y mantener información clave disponible para productores que necesitan decisiones rápidas, incluso en jornadas de trabajo exigentes.

  • Convierte procesos manuales en registros claros y consultables.
  • Mejora la visibilidad de cada etapa productiva.
  • Diseñada como PWA para acceso ágil desde cualquier dispositivo.

ArtHuila

Marketplace / Comercio Local / Full-Stack

Next.js Tailwind CSS MongoDB

ArtHuila conecta artesanos del Huila con compradores que buscan productos auténticos. El proyecto transforma una vitrina local en una experiencia digital cuidada, con navegación simple, presentación visual atractiva y una estructura pensada para impulsar ventas.

  • Fortalece la presencia digital de emprendimientos artesanales.
  • Organiza productos para facilitar descubrimiento y compra.
  • Equilibra identidad cultural con una experiencia moderna.

SIRC

Registro Ciudadano / Offline-first / Sincronización

Flutter SQLite Firebase

SIRC está pensado para contextos donde la conectividad no siempre acompaña. Permite capturar información ciudadana de forma local, conservar los datos y sincronizarlos cuando la señal vuelve, reduciendo pérdida de información y mejorando la continuidad del trabajo en campo.

  • Garantiza captura de datos aun sin conexión estable.
  • Reduce reprocesos y pérdida de registros importantes.
  • Prioriza almacenamiento local, sincronización y confiabilidad.

G - Juicios

Sistema Web / Gestión Académica / Automatización

PHP MySQL JavaScript

G - Juicios centraliza el registro y seguimiento de juicios evaluativos para hacer más eficiente la gestión académica. El sistema ayuda a ordenar información, consultar avances y reducir tareas repetitivas dentro de procesos institucionales.

  • Centraliza información académica en un flujo más organizado.
  • Agiliza consultas y seguimiento de aprendices.
  • Reduce carga operativa en procesos evaluativos.
